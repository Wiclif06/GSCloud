# Exemplos de JSON

Os IDs 1 dos exemplos precisam ser substituídos pelos IDs reais de farms/crop_areas. Datas representam demonstração em novembro de 2026; use datas não futuras e atualize os timestamps para o cenário mostrado. GET e DELETE não recebem corpo JSON. Para autenticação, use Swagger/Postman e o contrato original de /api/auth/register e /api/auth/login. Nunca exporte token/senha preenchidos.

Para o roteiro automático com IDs e datas atuais, use scripts/smoke-test.ps1. A coleção original do projeto foi preservada em postman/AgroConecta.postman_collection.json. Ela também contém contratos adicionais da solução; confira a versão do Swagger publicado.
